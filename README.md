# event-calendar

Group reminders by ISO dates in a local personal calendar.

Small, dependency-light Vanilla JavaScript utility. Original implementation and history generated for a retrospective development exercise.

## Usage

Open `index.html` in a browser and paste your entries. Click **Analyze** to inspect structured results. The editor stores a local draft in `localStorage`. Use **Export JSON** to make a portable report.

Run `node tests.js && node tests-edge.js` for the data-engine tests. No runtime dependencies.

Press Ctrl+Enter (Cmd+Enter on macOS) to analyze without reaching for the mouse.
